# Changelog

## 0.1.0-alpha.2 — 2026-10-21

- Added 89 exact plain dialogue keys and two Thai rank/name labels; total 6,537 lookup entries.
- Fixed the three missing Dunn lines and `Pvt. Cho` reported in the latest screenshots.
- Expanded short Park dialogue and shop conversation; new text remains draft pending context review.
- Added four screenshot probes, checked in every subtitle-size binary.
- Supports updating alpha.1 while preserving the original backups and selected subtitle size.
- Full campaign coverage and the new text in the running game are not yet verified.

## 0.1.0-alpha.1 — 2026-10-21

- First AKIE public-source project, based on the local v4 translation work.
- 6,446 lookup entries, including plain dialogue, dialogue choices and Thai speaker/rank labels.
- Folder-picker installer, independent backups for root/sp26, uninstall, size switching and diagnostics.
- Public packages exclude third-party loader binaries; supported files are imported locally.
- Reproducible no-op compatibility helper with its own source.
- Translation validation, source/data ZIPs, checksums, GitHub issue templates and CI/release workflows.

Full campaign translation, linguistic review and mission-by-mission in-game verification are incomplete. This release must not be described as 100% Thai.
