# งานก่อนรุ่นแคมเปญครบ

- [x] ตรวจคีย์ซ้ำ ตัวแปร โค้ดสี การขึ้นบรรทัด และความยาว UTF-8 ก่อนสร้าง
- [x] ตัวติดตั้งเลือกโฟลเดอร์ สำรอง ถอนและตรวจไฟล์
- [ ] จับคู่ข้อความกับทุกภารกิจและเส้นทางบทสนทนา
- [ ] แปลบทพูดที่ไม่มีวงเล็บและข้อความแคมเปญที่ยังขาดทั้งหมด
- [ ] ตรวจตัวเลือกตอบ เป้าหมาย ชื่อและคำแนะนำที่เกี่ยวข้องกับแคมเปญ
- [ ] ตรวจศัพท์ทหาร น้ำเสียง ชื่อตัวละครและบริบททุกบท
- [ ] เล่นทดสอบครบภารกิจและทางเลือก บันทึกรุ่นเกม/หลักฐาน
- [ ] ตรวจฟอนต์ วรรณยุกต์ การตัดบรรทัด ความยาวชื่อ และจังหวะซับ
