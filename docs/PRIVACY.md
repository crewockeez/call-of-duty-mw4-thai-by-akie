# ข้อมูลจากตัวตรวจ

ตัวติดตั้งและตัวตรวจไม่ส่งข้อมูลออกอินเทอร์เน็ต `check_install.bat` บันทึกใน `diagnostics/last-check.json` ซึ่งอาจมีพาธเกม รุ่นไฟล์ แฮช ข้อความทดสอบ ตำแหน่งโมดูลที่อ่านได้ และท้าย log ที่มีอยู่

โฟลเดอร์ `diagnostics/` ไม่รวมใน source/data ZIP และถูก `.gitignore` ไว้ ก่อนโพสต์รายงานสู่ Issue สาธารณะ ให้ลบชื่อผู้ใช้และพาธส่วนตัว เหลือเฉพาะข้อมูลที่เกี่ยวข้องกับปัญหา
