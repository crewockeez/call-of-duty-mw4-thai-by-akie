# ติดตั้งและคืนค่า

ดาวน์โหลด `-data.zip` จาก Releases และแตกทั้งโฟลเดอร์ ผู้เล่นไม่ต้องติดตั้ง Python

## เตรียมตัวโหลด

โปรเจกต์ไม่แจก DLL ของบุคคลที่สาม ต้องมีตัวโหลดรุ่นที่รองรับอยู่ในเครื่อง ตัวอย่างคือ `MW4-Farsi v1.3/files` ที่มี `bink2w64.dll` และ `trhook.dll` ระบบตรวจแฮชก่อนนำเข้า จะไม่ใช้ `rtlcompanion.dll` แบบ RTL ของเปอร์เซีย

เปิด `prepare_runtime.bat` เพื่อเลือกโฟลเดอร์ได้ หรือเปิด `install.bat` ซึ่งเรียกขั้นตอนนี้ให้ครั้งแรก ไฟล์ถูกคัดลอกลง `runtime-local/` ในเครื่องเท่านั้น ไม่แก้เกมในขั้นตอนเตรียม และไม่นำโฟลเดอร์นี้เข้า ZIP สาธารณะ

## ติดตั้ง

ปิดเกม เปิด `install.bat` เลือกโฟลเดอร์หลักหรือ `sp26` ต้องมี `sp26-cod.exe` ตัวติดตั้งจะสำรองก่อนคัดลอกข้อมูลทั้งสองตำแหน่ง ตั้งภาษาเกม English และเปิด Subtitles ใช้สำหรับทดสอบ Campaign/Offline

หากลงแพ็กไทยพัฒนา v4/v3.1 มาก่อน ให้ถอนรุ่นเก่าก่อนลงรุ่นสาธารณะครั้งแรก compatibility helper สร้างใหม่จึงมีแฮชต่างจากแพ็กเก่า สคริปต์จะหยุดและแจ้งหากไม่สามารถอัปเดตตรงได้

## ถอนและอัปเดต

`uninstall.bat` คืนสภาพก่อนติดตั้ง ถ้าเดิมมีม็อดอื่นอยู่ก็คืนไฟล์เดิมนั้น เก็บ `sp26/.mw4-thai-backups` และ `sp26/mw4-thai-install.json` ไว้ระหว่างใช้งาน

`0.1.0-alpha.2` รองรับอัปเดตจาก `0.1.0-alpha.1`: ปิดเกม แล้วเปิด `update.bat` จากโฟลเดอร์แพ็กใหม่ เลือกโฟลเดอร์เกมเดิม ระบบจะเก็บข้อมูลสำรองและขนาดซับที่เลือกไว้

`update.bat` ใช้เมื่อรุ่นที่ติดตั้งมีข้อมูลสำรองและตัวโหลดตรงกับรุ่นใหม่ โดยไม่สร้างสำรองต้นฉบับทับของเดิม หากไฟล์ถูกเกมหรือม็อดอื่นเปลี่ยน จะหยุดเพื่อให้ตรวจสอบ

## การตรวจปัญหา

`check_install.bat` ตรวจแฮช ไฟล์ทั้งสองตำแหน่ง และคีย์ทดสอบ ผลที่ตรงกับแพ็กไม่ยืนยันว่าตัวโหลดรองรับเกมทุก build หากซับยังอังกฤษ ให้แนบข้อความ/ชื่อภารกิจและผลตรวจที่ลบข้อมูลส่วนตัวแล้วใน Issue
